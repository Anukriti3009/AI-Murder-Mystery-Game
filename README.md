# 🕵️ AI Murder Mystery Detective

An AI-powered detective game built with Streamlit and Google Gemini.

Every game generates a completely new murder mystery with:
- A random victim
- A unique crime scene
- Three suspects
- Alibis
- Clues
- Logical deductions

The player must investigate evidence, analyze suspect alibis, and identify the murderer.

---

## Features

- 🤖 Gemini AI generated mysteries
- 🕵️ Detective-themed interface
- 📋 Evidence board
- 👥 Suspect cards
- 📝 Detective notebook
- 🎯 Multiple difficulty levels
- 🏆 Detective ranking system
- 🔄 Infinite replayability

---

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/ai-murder-mystery.git
cd ai-murder-mystery
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Setup

Create a file called:

```text
gemini_api_key.txt
```

Add your Gemini API key inside:

```text
YOUR_API_KEY_HERE
```

---

## Run

```bash
streamlit run app.py
```
